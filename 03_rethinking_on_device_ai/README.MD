03 — Rethinking On-Device AI
Understand how today's phones run AI locally.
Study the relationship between CPU, GPU, NPU, memory, and AI models.
Run a real model on a device.
Measure performance, memory usage, latency, and power.
Identify limitations in today's architecture.
Experiment with alternative ways of running AI locally.
Outcome: Develop the ability to identify opportunities for improving on-device AI.
