01 - From Logic to Silicon
Understand how a computer is built from basic digital logic.
Learn binary, logic gates, registers, memory, and a CPU.
Design a simple CPU using Verilog/SystemVerilog.
Simulate the CPU and run simple programs on it.
Understand the relationship between hardware instructions and software.
Eventually put the design onto an FPGA.
Outcome: Understand the fundamentals of digital chip design.
